## Original-derived correction

The paired official v3.5.0 and Nex evidence showed two concrete default-Popup differences:

- Nex was hard-coded to a 320-pixel Popup while the original evidence surface was 440 pixels wide;
- Nex permanently exposed the default `auto switch` result label and result selector even while System or Direct was active, whereas the original default Popup showed only the profile rows and Options entry.

The correction therefore:

- changes the Popup document and shell width from 320 pixels to 440 pixels;
- renders a Switch or Virtual result label only while that exact profile route is active;
- renders its result selector only while that exact profile route is active;
- keeps the active Switch/Virtual result-selection capability intact;
- adds Chromium coverage proving the inactive default Switch exposes no result label or selector in the System state;
- adds Firefox coverage proving the inactive default Switch exposes no result label or selector in the Direct state.

The UI compatibility guard was also corrected from the redesign-era 320-pixel requirement to the paired original evidence contract. It now requires:

- 440-pixel Popup width and absence of the obsolete 320-pixel rule;
- active-route gating in the Popup renderer;
- Chromium and Firefox inactive-result regression coverage.

The correction and its evidence guard passed architecture, parity, localization, type checking, unit tests, component tests, lint and diff validation before being committed. Temporary patch scripts were removed in the same transaction.

## Localization inventory correction

The generated locale scanner initially interpreted the Svelte expression `item.resultItems.length > 0 && ...` as a user-visible English fragment. The expression was rewritten to the semantically equivalent `item.resultItems.length !== 0 && ...`, and the locale inventory was regenerated by the repository tool. No UI text, control behavior or allow-list exception was introduced. The correction passed the same atomic verification and removed its temporary scripts in the commit transaction.

## Latest paired evidence

The paired artifact for ordinary Head `effa703f083cb9f196cada55185a59385c637567` confirms that the default Nex Popup now has the same 440-pixel viewport and the same five visible entries as the official v3.5.0 Popup. The inactive `auto switch` result label and selector are absent.

Remaining Popup differences are visual rather than structural: icon forms, row height and padding, active border/background geometry, divider placement and the Options entry styling. The Options page remains materially divergent in sidebar width, wrapping, spacing and About-page composition and is the next correction surface after permanent gates pass.
