# MIG-01 Existing Asset and Gap Inventory

## 1. Scope

This inventory tracks the importer, original and synthetic corpus, acceptance transaction, activation, packaged-browser evidence, semantic export, and remaining migration debt.

Evidence levels remain distinct:

1. original-runtime-produced data;
2. synthetic schema fixtures;
3. background/package integration tests;
4. packaged real-browser journeys.

A lower-level pass does not close the parent migration journey.

## 2. Current pipeline

```text
File or online text
  -> importZeroOmegaBackup
  -> compatibility report + inactive candidate + secret materials
  -> user review
  -> accept-import
     -> secret snapshot/write
     -> Draft replacement
     -> rollback Draft/secrets on acceptance failure
  -> apply
     -> validate / compile / install / confirm
     -> preserve or restore prior Applied/runtime state on failure
  -> active browser state
  -> browser restart recovery
  -> exportZeroOmegaBackup
  -> schemaVersion:2 backup
```

The ordinary “导入并立即使用” UI still composes `accept-import` and `apply`; it is not one background command.
